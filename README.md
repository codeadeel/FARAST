# Face Analytics: Detection, Alignment, Anti-Spoofing, Recognition
![DockerHub CI][dockerBadge]

![Face Analytics Architecture][architecture]

The subject repository assumes the role of overseeing Face Analytics. The underlying architecture of this subject repository has been trained utilizing the [Wider Face Dataset][datasetLink]. Presently, the realm of face analytics encompasses the subsequent key functionalities:

* Precise Face Detection
* Accurate Face Landmarks & Alignment
* Robust Face Anti-Spoofing Measures
* Advanced Face Recognition Capabilities
* Effective Batched Multi-Stream Face Tracking
